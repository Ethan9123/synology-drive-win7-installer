Synology Drive Win7 工具使用说明

这是实验性的受控安装工具，尚未完成 Win7 实机部署验收。
完整说明见 README.md；验收与回退见 docs\ACCEPTANCE.md。

1. 双击“一键安装.cmd”只做只读检查，不提权、不安装、不改系统。
2. 使用 Windows PowerShell 5.1。PS2 会提前停止；不要仅因脚本能打开就认为兼容。
3. 在能访问官方源的 Windows 准备机运行：
   powershell.exe -NoProfile -File .\Install-SynologyDrive.ps1 -Mode DownloadOnly
4. 把完整文件夹和 downloads 缓存复制到有快照的隔离 Win7 SP1 测试机。
5. 核查两个包的来源、SHA256、签名状态及安全软件告警。
6. 阅读验收说明后，在管理员 Windows PowerShell 中显式运行：
   powershell.exe -NoProfile -File .\Install-SynologyDrive.ps1 -Mode Install -Offline

VxKex 固定为 1.2.3.2466 Release，没有嵌入数字签名。
安装模式会展示其系统改动，并要求输入该样本的完整 SHA256。
这个确认仅限本次运行，不等于安全鉴定，也不会放过其他签名错误。

遇杀毒告警停止核查，不关闭防护、不给整目录或 PowerShell 添加排除。
工具不更改全机 TLS、BITS 或杀毒设置，不自动选择最新/Debug/旧缓存。
Offline 禁止工具下载；Windows 签名验证仍可能尝试证书链/吊销查询。

安装成功退出码后仍需找到预期文件版本；需要重启就停在待重启状态。
找到两个版本也不等于部署验收完成：还要配置兼容层，测试真实文件内容、
冲突、删除传播、断网恢复、重启及卸载回退。只用测试 NAS 与测试账号。

diagnose-launch.ps1 会主动尝试启动客户端，不属于只读预检。
verify-autostart.ps1 可在明确选择后修改快捷方式，默认跳过。
不要通过只改版本号、清空哈希或关闭证书验证来处理失败。
