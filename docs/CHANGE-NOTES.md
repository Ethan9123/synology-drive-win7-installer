# 从 PR #4 基线迁移

基线提交：`512f9ebce003f8753a62eac439bf20943dbaca5b`。

| 原行为 | 新行为 | 使用影响 |
|---|---|---|
| 双击即提权进入安装 | 默认 CheckOnly，无自动提权 | 实际安装必须明确选择 Install 并使用管理员会话 |
| 部分 PS2 兼容、缺命令后继续 | Windows PowerShell 5.1 为明确门槛 | PS2 提前停止；不提供未经验证的联网/离线支持承诺 |
| VxKex 运行时追踪 latest | 固定 Release 1.2.3.2466、精确大小和 SHA256 | 固定了字节身份，没有把该组合宣称为通过 Win7 验收 |
| 任意 KexSetup*.exe 大文件缓存 | 精确清单与统一校验 | 手工放包也不能绕过验证；Debug/其他版本不会自动选中 |
| 下载直接写最终文件 | 独立 .part，验证后原子提交 | 错误哈希阻断，不继续换源；所有传输异常清理半包 |
| GitHub 镜像自动回退 | 显式 opt-in，仍要求固定 hash | 优先官方准备机 + 离线分发 |
| 自动写 TLS / 重启 BITS | 只读检查系统，Web 请求只临时用进程 TLS1.2 | 不覆盖既有安全策略；网络准备由管理员单独处理 |
| 建议停杀软或目录白名单 | 报警停止、记录、复核 | 不保证所有安全产品都能无例外安装 |
| 安装器退出即继续 | 校验两个包后执行，检查退出码和组件版本 | 取消、失败和未知状态阻断；需重启状态单独报告 |
| 搜索 VxKex*.exe 作为设置界面 | 按安装信息定位 KexCfg.exe | 不再误选 VxKexLdr.exe |
| 自动配置自启/启动客户端 | 主流程只提示手动配置与验收 | 减少安装阶段直接触及同步数据；自启辅助工具默认跳过修改 |

此次新增的安装边界、签名规则与私有临时目录均需 Windows 7 实机验证。离线测试模拟安装进程和签名结果；它们证明分支与失败处理，不证明上游 EXE 的行为。

旧 PR #1 不包含本次实现，也没有合并、关闭或重写。日后若需要更新发现，应生成待审清单，经过安全与配对验收后再改固定版本，不让安装端自动追踪最新。
